## 4. Long Description（长描述，300 词以内）

```
PRD Chart is an AI-powered diagramming tool built to bridge the gap
between written product requirements and visual communication. Product
managers, designers, and engineers can paste a PRD directly into the
editor or upload a .docx or .txt file, and the app will instantly
transform the prose into a clean, well-structured Mermaid diagram.

Three diagram types are supported out of the box: sequence diagrams
for API and interaction flows, flowcharts for decision logic and
business processes, and user journey maps for visualizing end-to-end
user experiences. Every generated diagram can be refined in a
full-featured Monaco code editor with syntax highlighting, so power
users can fine-tune the underlying Mermaid syntax without leaving the
app.

A library of six professionally designed color themes — including
purple, blue, green, orange, pink, and glassmorphism — lets teams
match the diagram to their brand. Once finalized, diagrams can be
exported to SVG or PNG, copied to the clipboard, or shared via a
unique URL for stakeholder review.

The app uses a simple credit-based pricing model: every diagram
generation costs 3 credits, and a free tier gives 12 credits on
signup plus 3 daily credits. Paid plans unlock larger credit
allowances, priority queue processing, commercial usage rights,
and email support. Payment is handled securely through PayPal, and
user accounts are powered by Supabase authentication.

PRD Chart is built with a modern React + Vite stack, designed to
feel as fast and responsive as the diagrams it produces.
```
(273 words)

## 12. Common Q&A（常见问答，PH 评论区 / FAQ 备用）

```
Q: How is this different from ChatGPT or other AI chat tools?
A: PRD Chart is purpose-built for the PRD → diagram workflow.
   You get a focused editor, Mermaid syntax validation, color
   themes, and one-click export — no copy-pasting into a chat
   window or fixing broken syntax by hand.

Q: What diagram formats are supported?
A: Sequence diagrams, flowcharts, and user journey maps — the
   three most common types in product documentation.

Q: Can I edit the generated diagram?
A: Yes. The output is editable Mermaid code in a Monaco editor,
   so you can tweak anything before exporting.

Q: Do I need an account?
A: Only to save, share, or exceed the free daily credits. You
   can try the tool without signing up.

Q: Is there a free tier?
A: Yes — 12 credits on signup, plus 3 daily credits forever.
   Each diagram costs 3 credits.

Q: Can I use the diagrams commercially?
A: Yes, on the Pro plan. The Pro plan also unlocks priority
   queue processing and email support.

Q: What payment methods are supported?
A: PayPal, including credit cards paid via PayPal.
```
